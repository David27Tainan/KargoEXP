魔龍經驗KargoEXP · 使用說明

使用說明更新紀錄下載最新版

量「這張地圖一小時能賺多少經驗、花多少水錢」的小工具，給新楓之谷：經典版用。

只做螢幕截圖 + 文字辨識。不讀遊戲記憶體、不注入、不送任何鍵盤滑鼠事件給遊戲。

1. 安裝（三步）

  1. 到 Releases 下載 KargoEXP.exe，放進一個空資料夾（它會在旁邊自己生出 config.yaml 跟 data\）。
  2. 遊戲用視窗模式開著。內建座標是 1382×807 量的；別的大小（例如 1920×1080）開程式後按一次「自動定位」就好（第 3 節）。
  3. 點兩下 KargoEXP.exe。第一次開約 3 秒。地圖／等級／經驗會自己出現。

不用裝 Python。遊戲視窗被其他視窗蓋住也讀得到，只有最小化不行。Windows 縮放 125% 也可以。

2. 主視窗

地圖 / Lv.現在讀到的地圖名、等級與經驗百分比。
經驗/hr一小時經驗。點右邊的小方框可切成 經驗/10min（近十分鐘）。
距離升級照目前速度還要多久升級。
水錢/hr一小時藥水錢，後面 [🔴瓶數/🔵瓶數]。楓幣數字的顏色跟遊戲商店標價同一套（越貴越深）。跟上面那個方框連動，同樣可切 10min。
本次計時按「開始」之後累計的時間。
開始 / 結束按「開始」才會計時、才會寫進紀錄。沒按只是預覽。換地圖記得結束再開始，不然會混在一起。
紀錄右上角的鈕。展開排行榜：每張地圖的 經驗/hr、經驗/10min、藥水費/hr、藥水費/10min。同一排有「校準」「檢查更新」「使用說明」「清除全部紀錄」。
右邊那條（健康列）每一塊有沒有讀到：綠水靈＝剛讀到、灰的＝一陣子沒讀到、紅叉＝讀壞了。全部綠了會自己往左滑進去收起來；要再看，按「紀錄」左邊那顆紅色小箭頭。底下「校準」直接開校準頁。

顯示「—」代表資料還不夠（剛開始要等幾分鐘），不是壞掉。紀錄存在 data\歷史紀錄.csv，Excel 開得動。

3. 讀不到、讀錯時：校準

連續讀不到會自己跳視窗問你要不要校準。手動的話：按「紀錄」→「校準」，或健康列的「校準」。

  1. 先按右下角「自動定位」。它會在畫面上找等級徽章、商店鈕、小地圖、快捷欄，六塊位置一次填好。上面會寫找到了幾個；哪一塊沒找到會用橘字說。
  2. 看「讀到」那欄。✓ 就是對的，✗ 會直接寫哪裡壞了。
  3. 差一點點：點左邊那一列的名字（會變粉紅），用下面的 ↑ ← → ↓ 跟 寬− 寬+ 高− 高+ 微調。
  4. 差很多：點名字後按「重新框選」，整個桌面變半透明，用滑鼠拖一個框把那塊字圈起來，放開就好（Esc 取消）。
  5. 都 ✓ 之後按「儲存」。存一次以後重開程式、重開電腦都不用再做。
框的範圍：經驗值只框 EXP 4679[85.70%] 那一行；地圖名稱只框名稱那兩行，不要把整個小地圖框進去；等級只框 LV. 旁邊的數字。「範例」那欄是你按「存成範例」存下來的對照圖。

4. 水錢（藥水花費）

預設：End 格是紅水（320 楓幣）、Pdn 格是藍水（200 楓幣）。你的快捷欄不一樣的話，到「藥水」分頁最下面改「血水在哪一格」「藍水在哪一格」跟價格，按「儲存」。

  • 「快捷欄」那列會把你的 2×4 快捷欄自動分成 8 格，選中的格子會有綠框。
  • 藥水數量讀到 ✓ 就對了。它是算「瓶數變少了多少」，補貨（數字變多）不會算成花費。
  • 不想看水錢：把兩個下拉都選「未設定」再儲存，主視窗那行就會消失。經驗統計完全不受影響。

5. 更新

按「紀錄」→「檢查更新」。有新版會問你要不要下載，下載完自動換檔重開，你改過的 exe 檔名會保留。「使用說明」鈕會開這份說明；每一版多了什麼看頁頂的 更新紀錄。

6. 常見狀況

地圖名一直 ???到校準頁按「自動定位」再儲存。還是不行就用「重新框選」手框。
經驗一頓一頓、每 3 秒才跳遊戲改版把介面搬家了。到校準頁「自動定位」→ 儲存。
健康列一直紅叉那一塊讀壞了，按「校準」去看「讀到」那欄寫什麼。
視窗開不起來 / 閃退看 exe 旁邊 data\錯誤紀錄.txt，把內容寄到 maplestockdata@gmail.com（第 7 節）。
換電腦、換帳號整個資料夾複製過去即可。不想帶舊成績就刪 data\歷史紀錄.csv。

7. 聯絡／回報問題

有問題、讀錯、閃退，或想建議功能，寄信到 maplestockdata@gmail.com。 回報錯誤請附：data\錯誤紀錄.txt 的內容、遊戲視窗大小、螢幕縮放比例，最好再附一張校準頁的截圖。

此程式內含遊戲原廠素材，僅供自用，請勿公開散布。
